# Discord Ticket Bot

بوت تذاكر ديسكورد مع دعم اللغة العربية وقاعدة بيانات MongoDB للحفظ الدائم.

## الأقسام
- 🛒 **شراء** — تذاكر الشراء
- ↩️ **استرجاع** — تذاكر الاسترجاع
- 🛠️ **دعم فني** — تذاكر الدعم الفني

## المتغيرات المطلوبة على Railway
| المتغير | الوصف |
|---------|-------|
| `TOKEN` | توكن بوت الديسكورد |
| `CLIENT_ID` | معرف تطبيق الديسكورد (Application ID) |
| `MONGODB_URI` | رابط الاتصال بقاعدة بيانات MongoDB Atlas |

## إعداد MongoDB Atlas (مجاني إلى الأبد)
1. اذهب إلى https://www.mongodb.com/atlas
2. أنشئ حساباً مجانياً
3. أنشئ Cluster جديد (اختر M0 Free)
4. من **Database Access** أنشئ مستخدماً وكلمة مرور
5. من **Network Access** اضغط **Add IP Address** ثم **Allow Access from Anywhere**
6. من **Connect** اختر **Drivers** ثم انسخ رابط الاتصال
7. ضع الرابط في متغير `MONGODB_URI` على Railway

## الأوامر
| الأمر | الوصف |
|-------|-------|
| `/ticket` | إرسال لوحة التذاكر |
| `/setup-logs` | تحديد قناة السجلات |
| `/setup-staff` | تحديد رتبة الإدارة |
| `/setup-category` | تخصيص رتبة لكل قسم |
| `/close-ticket` | إغلاق التذكرة وحفظ السجل |
| `/rename-ticket` | إعادة تسمية قناة التذكرة |
| `/add-user` | إضافة مستخدم للتذكرة |
| `/remove-user` | إزالة مستخدم من التذكرة |
| `/ticket-stats` | عرض الإحصائيات |
| `/reset-stats` | إعادة تعيين الإحصائيات |
| `/help` | عرض جميع الأوامر |
| `/staff-help` | أوامر الإدارة |

## الاستضافة على Railway
1. أنشئ مشروعاً جديداً على https://railway.app
2. اربط المستودع من GitHub
3. أضف المتغيرات الثلاثة (`TOKEN`, `CLIENT_ID`, `MONGODB_URI`)
4. سيبدأ التشغيل تلقائياً

## ما الذي يُحفظ في قاعدة البيانات؟
- تسلسل أرقام التذاكر (لا يُعاد من 1 عند إعادة النشر)
- الرتب المخصصة لكل قسم
- قناة السجلات
- رتبة الإدارة العامة
- إحصائيات التذاكر (مفتوحة / مغلقة)
- من استلم كل تذكرة
