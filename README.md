# Discord Ticket Bot

بوت تذاكر ديسكورد مع دعم اللغة العربية وقاعدة بيانات MongoDB للحفظ الدائم.

## الأقسام
- 🛒 **شراء** — تذاكر الشراء
- ↩️ **استرجاع** — تذاكر الاسترجاع
- 🛠️ **دعم فني** — تذاكر الدعم الفني

## المتغيرات المطلوبة على Railway
| المتغير | الوصف |
|---------|-------|
| `TOKEN` | توكن بوت الديسكورد |
| `CLIENT_ID` | معرف تطبيق الديسكورد (Application ID) |
| `MONGODB_URI` | رابط الاتصال بقاعدة بيانات MongoDB Atlas (يفضل `mongodb+srv://...`) |
| `MONGODB_DB_NAME` | اسم قاعدة البيانات (اختياري، الافتراضي `ticket-bot`) |
| `MONGODB_TLS` | تفعيل TLS (اختياري؛ الافتراضي `true` تلقائياً مع `mongodb+srv://` و`false` مع MongoDB الداخلي بصيغة `mongodb://`) |

## إعداد MongoDB Atlas (مجاني إلى الأبد)
1. اذهب إلى https://www.mongodb.com/atlas
2. أنشئ حساباً مجانياً
3. أنشئ Cluster جديد (اختر M0 Free)
4. من **Database Access** أنشئ مستخدماً وكلمة مرور
5. من **Network Access** اضغط **Add IP Address** ثم **Allow Access from Anywhere**
6. من **Connect** اختر **Drivers** ثم انسخ رابط الاتصال
7. ضع الرابط في متغير `MONGODB_URI` على Railway، وتأكد من أن كلمة المرور مشفّرة داخل الرابط إذا احتوت على رموز مثل `@` أو `#`
8. من **Network Access** أضف `0.0.0.0/0` حتى تسمح لـ Railway بالاتصال

### حل خطأ SSL / فشل الاتصال
- استخدم رابط **Drivers** الذي يبدأ بـ `mongodb+srv://` بدل رابط لوحة التحكم أو رابطاً منسوخاً ناقصاً.
- في Railway ألصق الرابط بدون مسافات أو أسطر جديدة، ولا تضعه بين علامات اقتباس؛ الكود يزيل علامات الاقتباس الخارجية تلقائياً لكن الأفضل حفظ القيمة بصورتها الأصلية.
- إذا كانت قاعدة البيانات MongoDB مضافة داخل Railway وكان الرابط يبدأ بـ `mongodb://`، اترك `MONGODB_TLS` فارغاً أو اضبطه على `false`. إذا كانت MongoDB Atlas، استخدم `mongodb+srv://` واترك TLS مفعلاً.
- تأكد أن مستخدم قاعدة البيانات لديه صلاحية على قاعدة البيانات، وأن اسم المستخدم وكلمة المرور صحيحان.
- إذا كانت كلمة المرور تحتوي على `@` أو `:` أو `/` أو `#` أو `%`، قم بترميزها بصيغة URL قبل وضعها في `MONGODB_URI`.
- لا تضف `tlsAllowInvalidCertificates=true`؛ هذا يخفي المشكلة ويضعف أمان الاتصال.
- بعد تعديل متغيرات Railway، أعد تشغيل الخدمة حتى تستخدم القيم الجديدة.

## الأوامر
| الأمر | الوصف |
|-------|-------|
| `/ticket` | إرسال لوحة التذاكر |
| `/setup-logs` | تحديد قناة السجلات |
| `/setup-staff` | تحديد رتبة الإدارة |
| `/setup-category` | تخصيص رتبة لكل قسم |
| `/close-ticket` | إغلاق التذكرة وحفظ السجل |
| `/rename-ticket` | إعادة تسمية قناة التذكرة |
| `/add-user` | إضافة مستخدم للتذكرة |
| `/remove-user` | إزالة مستخدم من التذكرة |
| `/ticket-stats` | عرض الإحصائيات |
| `/reset-stats` | إعادة تعيين الإحصائيات |
| `/help` | عرض جميع الأوامر |
| `/staff-help` | أوامر الإدارة |

## الاستضافة على Railway
1. أنشئ مشروعاً جديداً على https://railway.app
2. اربط المستودع من GitHub
3. أضف المتغيرات الثلاثة (`TOKEN`, `CLIENT_ID`, `MONGODB_URI`)
4. سيبدأ التشغيل تلقائياً

## ما الذي يُحفظ في قاعدة البيانات؟
- تسلسل أرقام التذاكر (لا يُعاد من 1 عند إعادة النشر)
- الرتب المخصصة لكل قسم
- قناة السجلات
- رتبة الإدارة العامة
- إحصائيات التذاكر (مفتوحة / مغلقة)
- من استلم كل تذكرة
